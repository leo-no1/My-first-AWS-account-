## Creating My AWS Account

In this step, I'm going to signing up and filling all the required information for creating a personal AWS account by providing our email and verifying the same. Also creating a strong password for the accound.

### Understanding the root user

I learned that a root user is he main account owner with full access to everything in your AWS account. Every AWS account has exactly one root user, and it is created during sign-up. And that's why a strong password is required for the root user.

## Setting Up Billing and Payment

In this step, I'm going to choose a free tier subscription for my account by which i'll be getting few credits and acces to limitted resources. Completing the contact information and setting up payment.

### Why AWS requires a payment method

I learned that AWS requires a payment method because AWS asks for your payment method for two main reasons:
1. They want to make sure you’re a real person (not a bot trying to get free cloud resources).
2. If you choose to go past your Free Tier limits, they need a way to charge for that extra usage.

## Securing the Account with MFA

To enable MFA, I used google authenticator app for the same and scanned the qr code provided by aws onto the authenticator app. The authenticator app works by generates a new 6-digit code every 30 seconds. When you log in to AWS, you enter your password and the current code from the app.
